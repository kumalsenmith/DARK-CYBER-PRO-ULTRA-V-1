PRIVACY AND SAFETY
------------------
This is a local educational cyber-themed simulator. The radar, globe signals,
scanner, firewall results, decryption and access sequence are fictional. They
do not scan networks or access other systems. The command center is an
allowlisted in-app command interface, not a Windows shell.

Accounts, preferences and activity are stored in this browser's localStorage.
Do not use real passwords or sensitive information in this demo. Password
checks and file hashing run locally; selected files are not uploaded.

TESTING

The JavaScript syntax passed Node.js validation. The HTML was parsed and checked
